# ABYSSAL · 深渊猎游

驾驶一只年轻虎鲸，从阳光下的珊瑚礁游向火山深渊。捕食、成长、逃离猎手，在接近食物链顶端时挑战拥有独立技能的深海主宰。

[在线试玩](https://stanatny.github.io/abyssal/) · [公开 GitHub 仓库](https://github.com/stanatny/abyssal)

当前为 **v0.2 反馈迭代版**。这一轮回应配乐、水面跃起、奖励辨识、海域纵深、生物分级、领地战和进食回血七项试玩反馈。本轮26项规则测试与21条浏览器流程已通过；自然游玩的节奏和难度仍需试玩。GitHub Pages 通过 `main` 分支的 Actions 工作流发布。

## v0.2 当前实现

- 虎鲸第三人称追尾视角，鼠标或键盘控制转向、上浮、下潜、冲刺和慢游。
- 6 米起步；**达到 30 米并至少击败一位深海主宰**才获胜。
- 普通鱼自动捕食；受伤时优先修复生命，并减少本次成长收益，饱食仍正常补充。
- 初级鱼群、中级猎手、稀有领地主宰三层生态。大白鲨、鮟鱇、大王乌贼和邓氏鱼可用冲刺脱险。
- 克拉肯、玛雅巨兽、三头海德拉、利维坦四种主宰，每局随机启用两只，各有领地、技能预警、生命值与攻击后 3 秒虚弱期，需要多次主动咬击。
- 扩展到最大 740 世界单位的纵深，深度显示约 2960 米，加入更深的环境层次与探索区域。
- 冲刺向上可跃出水面，在空中捕食海鸥，再以抛物线落水。
- 三类奖励有独立图形、名称、效果文字与声音。
- 原创程序化背景音乐：平静探索的旋律与和声、追击节拍、主宰战鼓平滑切换；另有捕食、受伤、出水、落水、奖励和胜利音效。
- 暂停、重开、声音开关、画质切换，以及基础触屏摇杆和按钮。

角色仍固定为虎鲸。当前为程序化 3D 原型，以上表示已进入本轮实现的内容，不代表已经完成全部体验验收。七项反馈的来源、取舍和验证状态见 [反馈记录](docs/feedback_v0_2.md)。

## 操作

| 操作         | 控制方式                                     |
| ------------ | -------------------------------------------- |
| 转向与俯仰   | 移动鼠标，靠近画面中心时趋于直游             |
| 上浮 / 下潜  | W / S                                        |
| 左右转向     | A / D                                        |
| 冲刺         | 按住空格，消耗体力                           |
| 慢游         | 按住 Shift                                   |
| 主动咬击主宰 | F 或鼠标左键，靠近目标后攻击                 |
| 水面跃起     | 在接近水面时向上冲刺                         |
| 声呐         | E，辅助识别目标与距离                        |
| 暂停 / 继续  | Esc、P 或界面按钮                            |
| 触屏控制     | 使用界面摇杆和动作按钮，手感仍待真实设备验证 |

虎鲸会持续向前游动。松开冲刺可以恢复体力；耗尽体力后需要恢复到阈值才能再次冲刺。体力耗尽本身不扣生命，饱食耗尽会持续扣生命。

中级猎手可以靠冲刺、地形遮挡和拉开距离摆脱。高级主宰的追击速度高于普通冲刺，需要观察前摇、横向闪避、切换水层或撤出领地，不能只直线加速。

## 奖励

| 奖励     | 识别图形   | 效果                                                                                   |
| -------- | ---------- | -------------------------------------------------------------------------------------- |
| 体力泉   | 绿色十字   | 体力立即回满，解除疲惫                                                                 |
| 洋流之息 | 蓝色双箭头 | 12 秒内冲刺不耗体力                                                                    |
| 深渊狂食 | 橙色獠牙   | 10 秒内可吞食自身 1.6 倍体长以内的普通猎物；主宰咬击体长门槛降低到 21 米，仍需多次战斗 |

画面显示的**深度 = 世界坐标海深 × 4**。世界最大海深 740 对应约 2960 米；实际可抵达位置还受海床与角色体型影响。深度、体长与速度采用游戏尺度，不作为物理或生物模拟。

## 本地运行

需要 Node.js 20.19+（20.x 系列），或 Node.js 22.12+ 的受支持版本，以及支持 WebGL 2 的现代浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。点击“潜入海洋”或首次点击声音按钮可激活音频。

```bash
# 构建静态网页
npm run build

# 预览构建结果
npm run preview

# 检查独立游戏规则
npm test

# 检查格式
npm run check

# 保留开发服务器，在另一终端验证浏览器关键流程
npm run test:browser

# 浏览器离线合成配乐，检查音量与暂停逻辑并输出试听 WAV
node scripts/verify_audio.mjs
```

浏览器脚本使用本机 Google Chrome，默认开发地址为 `http://127.0.0.1:5178`。如果 Vite 显示其他地址，可通过 `ABYSSAL_DEV_URL` 环境变量覆盖。输出记录、截图和试听文件位于忽略版本控制的 `.local/`。

构建产物位于 `dist/`。发布前应确认 `vite.config.js` 的站点路径、静态资源与各类设备表现。

## 当前限制与验证边界

场景与生物以原创程序化几何为主，没有精细贴图、专业角色资产或录制音效。普通 AI、碰撞、技能范围与生态仍有简化。成长节奏、治疗比例、主宰难度、相机、触屏和低性能设备帧率需要实测调优。

这是单机静态网页，不包含账号、联网对战或云端存档。当前局进度不保存；浏览器本地仅记录最佳体长。

本轮与第一版的验证记录分别保存在 [docs/verification.md](docs/verification.md)。开发状态跳转不代表自然操作完成一整局。
