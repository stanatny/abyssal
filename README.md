# ABYSSAL · 深渊猎游

选择虎鲸或大王乌贼，从阳光下的珊瑚礁游向火山深渊。捕食、成长、逃离猎手，在接近食物链顶端时挑战拥有独立技能的深海主宰。

[在线试玩](https://stanatny.github.io/abyssal/) · [公开 GitHub 仓库](https://github.com/stanatny/abyssal)

当前版本为 **v0.5.1 角色与生态扩展**；正式网页仍为已发布的 v0.2（`96d57ff`）。本轮加入第二角色、新物种、人类活动和侧翼领主战；大王乌贼仅作可选角色，野生头足类替换为独立章鱼；整体 UI 与视觉再设计留待下一轮。GitHub Pages 只发布已获授权推送到 `main` 的版本，当前临时预览及实际验收情况见 [验证记录](docs/verification.md)。

## v0.5 新增

两种角色均从 6 米开始，各有一个主动技能和一个被动。桌面按 J、手机按角色技能按钮释放主动；被动自动生效。

| 角色     | 主动技能                                                                                                                         | 被动技能                                                                  |
| -------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| 虎鲸     | 回声定位：探测 260 范围内生物 10 秒，前方显示体长/捕食资格，雷达显示周围回声；冷却 60 秒                                         | 海洋疾驰：冲刺比基础速度提高 30%，达到 41.6 游戏米/秒                     |
| 大王乌贼 | 墨幕喷射：水下释放，使 90 范围内正在追击的猎手及交战中的领主迷失并停留 10 秒；前 1.5 秒沿释放时朝向喷射，目标速度 72；冷却 60 秒 | 柔躯回旋：未冲刺时转向更快，上浮/下潜角度可达 85°；实际冲刺时恢复常规转向 |

乌贼的喷射受岩石、船体等实体阻挡，墨幕不是无敌。两角色共用巡游 12、慢游 5 游戏米/秒；乌贼普通冲刺为 32。

- 普通生物扩展到 **21 种**：10 种海洋猎物、5 种现代“海洋霸主”、6 种远古巨兽。新增鳀鱼、沙丁鱼、鲱鱼、鲭鱼、飞鱼、绿海龟、翻车鱼等；飞鱼受惊可破水滑翔。
- 现代猎手为深海鮟鱇、锤头鲨、大白鲨、北太平洋巨型章鱼、抹香鲸；远古生物为邓氏鱼、上龙、蛇颈龙、沧龙、龙王鲸、巨齿鲨。现代和远古类别内按体长排列，体长与水层重新校准。
- 四种稀有领主需要从**左右侧翼朝内接触攻击**；每次成功后须离开至少 0.35 秒再接近，并满足 1.2 秒咬击冷却。单击最多造成总生命 24% 的伤害，至少五次有效攻击，贴着不动不会连续扣血。
- 加入成年游泳者、成年潜水员、潜艇及鱼雷。至少 8 米的角色以不低于 20 的速度完成三次独立冲撞，可破坏潜艇并一次性释放三名潜水员。鱼雷接触后爆炸消失，造成 28 点伤害，不会反复结算。
- 图鉴扩展为 **32 条记录**，包括两个角色、21 个普通生物、海鸥、四个领主和四个人类活动条目。排除人类活动，共 **28 种独立海洋生物类型**；海洋奖励另列。

当前只有**夏威夷幻想海域**开放，本期全部物种集中在这里；马里亚纳海沟、百慕大三角、亚特兰蒂斯只展示尚未开放的入口。真实生物资料、古生物估计与幻想设定分开说明：这里并非真实夏威夷生态复刻，远古复苏、神话领主、超常成长和技能均属于游戏设计。体长、翼展、背甲长、乌贼含触腕全长也不能直接比较体量。来源及具体取值见 [生态资料](docs/ecology_sources_v0_5.md)，本轮决定见 [v0.5 反馈记录](docs/feedback_v0_5.md) 和 [v0.5.1 补充](docs/feedback_v0_5_1.md)。

## 玩法基础

- 第三人称追尾视角，桌面键盘或手机摇杆控制转向、上浮、下潜、冲刺和慢游。
- 6 米起步；**达到 30 米并至少击败一位深海主宰**才获胜。单局最多 30 分钟有效游玩时间，暂停不计，到时独立结算。
- 普通猎物接触自动捕食，无咬击按键。进食优先修复生命，饱食正常补充，本次成长收益按治疗占比减少；体型越大，极小猎物收益越低。
- 克拉肯、玛雅灵感原创巨兽、三头海德拉、利维坦四种主宰，每局随机启用两只，各有领地、技能预警、生命值与攻击后 3 秒虚弱期。通常长到 24 米才能伤害，狂食时门槛降至 21 米，仍需多次侧翼进攻。
- 常驻雷达显示固定北向海域、位置、航向、深浅区及克制的返航线，并提示返回出生浅滩需上浮的距离。平时不泄露全图生物，虎鲸声呐期间显示探测回声。
- 世界最大纵深 740，深度显示约 2960 米；实际可到达位置受海床与角色体型影响。
- 水下持续冲刺蓄势后，向上跨过水面可跃出，在空中捕食海鸥并以抛物线落水；已在水面或空中按冲刺不能再次起跳。
- 礁石、岩柱、岩拱、遗迹和船体有实体碰撞；角色可沿面滑动、绕过船底。游轮/帆船不可捕食或破坏，潜艇另有冲撞破坏规则。
- 原创程序化配乐在平静探索、追逐与主宰战之间切换；另有捕食、受伤、出水、落水、奖励和结算音效。
- 支持暂停、重开、声音开关、画质切换、首页常规标记设置及触屏操作。

参考事件模型按实际成长、饥饿和治疗规则计算：基准路线 **17:17**，假定事件耗时缩短 20% 为 13:49.6，延长 25% 为 22:51.25。模型有预设捕食间隔、转场和领主战结算，**不模拟自然导航、刷新等待或实际侧击战斗，也不代表已经实玩完整一局**。自然觅食、难度及真机手感仍需试玩调优。

## 操作

| 操作         | 控制方式                                                      |
| ------------ | ------------------------------------------------------------- |
| 上浮 / 下潜  | W / S                                                         |
| 左右转向     | A / D                                                         |
| 冲刺         | 按住空格，消耗体力                                            |
| 慢游         | 按住 K                                                        |
| 角色主动技能 | J；虎鲸为回声定位，乌贼为墨幕喷射，均冷却 60 秒               |
| 捕食 / 攻击  | 接触自动触发；领主需满足体长、侧翼及脱离再入条件              |
| 水面跃起     | 先在水下持续冲刺蓄势，再向上破水                              |
| 生物标记     | 仅首页设置常规体长/捕食提示；虎鲸声呐期间强制显示前方探测标记 |
| 暂停 / 继续  | Esc、P 或界面按钮                                             |
| 触屏控制     | 摇杆、冲刺和当前角色技能按钮；技能有倒计时与冷却禁用状态      |

角色会持续向前游动。松开冲刺可恢复体力；耗尽后需恢复到阈值才能再次冲刺。体力耗尽本身不扣生命，饱食耗尽会持续扣生命。手机游戏区关闭文字选择、长按菜单及复制粘贴触发，首页图鉴检索框保留正常编辑。鼠标可操作菜单与图鉴，桌面游泳只用键盘。

虎鲸声呐持续 10 秒：雷达记录 260 范围内的周围回声，画面仅显示相机前方水平 ±30°、垂直 ±25°且位于屏内的目标。它可揭示雾中和岩石后面的目标；转向后切换显示，同种同资格鱼群合并，最多四组，没有身后箭头或满屏连线。以虎鲸为中心的声波体现生效状态；结束后恢复首页的常规标记偏好。乌贼的主动技能不提供声呐侦察。

普通猎手可利用冲刺、地形遮挡和距离摆脱。虎鲸冲刺高于领主普通追速，但领主还会预判、吸引、施放脉冲/弹体或高速冲撞；利维坦冲撞速度达到 100。观察预警、横向闪避、切换水层或撤出领地仍然必要。

## 奖励

首页「海洋图鉴 → 海洋奖励」展示图形与用途。游戏画面不常驻奖励说明，拾取后显示限时状态；同类限时奖励再次拾取刷新到 30 秒，不累加。

| 奖励     | 识别图形   | 效果                                                                                 |
| -------- | ---------- | ------------------------------------------------------------------------------------ |
| 体力泉   | 绿色十字   | 体力立即回满，解除疲惫                                                               |
| 洋流之息 | 蓝色双箭头 | 30 秒内冲刺不耗体力                                                                  |
| 深渊狂食 | 橙色獠牙   | 30 秒内可吞食自身 1.6 倍体长以内的普通猎物；主宰攻击门槛降到 21 米，仍需多次侧翼战斗 |

画面显示的**深度 = 世界坐标海深 × 4**。体长、速度和深度采用游戏尺度，不作为完整物理或生态模拟。

## 本地运行

需要 Node.js 20.19+（20.x 系列），或 Node.js 22.12+ 的受支持版本，以及支持 WebGL 2 的现代浏览器。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。点击“潜入海洋”或首次点击声音按钮可激活音频。

```bash
# 构建静态网页
npm run build

# 预览构建结果
npm run preview

# 检查独立游戏规则
npm test

# 检查格式
npm run check

# 保留开发服务器，在另一终端验证浏览器关键流程
npm run test:browser

# 检查v0.5角色、图鉴、墨幕喷射、飞鱼与人类活动
node scripts/verify_expansion_v0_5.mjs

# 检查v0.3图鉴、技能、墨云和特效生命周期
node scripts/verify_feedback_v0_3.mjs

# 检查v0.4菜单、手机长按、设置与真实时钟
node scripts/verify_controls_v0_4.mjs

# 检查主动声呐的前方过滤、遮挡、真实转向、10/60秒与暂停重开
node scripts/verify_sonar_v0_4_1.mjs

# 检查六种尺寸与未来双技能布局
node scripts/verify_hud_v0_4_2.mjs

# 检查生命/体力/饥饿条对齐与动态副文案
node scripts/verify_vitals_v0_4_3.mjs

# 用真实输入检查礁石、船体、甲板、成长脱困和相机
node scripts/verify_collision_v0_4.mjs

# 浏览器离线合成配乐，检查音量与暂停逻辑并输出试听WAV
node scripts/verify_audio.mjs
```

浏览器脚本使用本机 Google Chrome，默认开发地址为 `http://127.0.0.1:5178`；可通过 `ABYSSAL_DEV_URL` 环境变量覆盖。输出记录、截图和试听文件位于忽略版本控制的 `.local/`。脚本名保留原始版本以兼容入口，实际断言随当前规则维护。

构建产物位于 `dist/`。发布前应确认 `vite.config.js` 的站点路径、静态资源与各类设备表现。

## 当前限制与验证边界

场景与生物以原创程序化几何为主，没有精细贴图、专业角色资产或录制音效；模型使用真实生物的辨识特征，不是科学复原。普通 AI、碰撞、技能范围与生态仍有简化。自然成长、治疗分配、领主难度、相机、真机触屏和低性能设备帧率需要实测调优，整体 UI 重绘仍待后续。

这是单机静态网页，不包含账号、联网对战或云端存档。当前局进度不保存；浏览器本地仅记录最佳体长和辅助标记偏好。

实际验收记录保存在 [docs/verification.md](docs/verification.md)。规则单测、开发接口布景和浏览器模拟手机尺寸不能替代自然 30 分钟整局或真实手机试玩。
