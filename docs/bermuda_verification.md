Codex independently authored and reviewed this candidate; no delegated assets are included. Main, GitHub Pages and the published version remain unchanged. Source scope and current gameplay are described in the [production contract](bermuda_brief.md), with references and reconstruction qualifications in the [art/audio notes](bermuda_art.md).
