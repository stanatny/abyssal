# v0.2 后续工作

## 当前进展与边界

本轮围绕七项试玩反馈，已加入分层配乐、修复优先进食、主宰战规则、奖励辨识、水面跃起和更深海域相关模块。详见 [feedback_v0_2.md](feedback_v0_2.md)。v0.2已通过26项规则测试与21条浏览器流程，用户于2026-09-27授权提交；自然整局体验与真实设备验收仍待继续，不把第一版验证记录当作 v0.2 已验收。

## 优先完成本轮联动验收

- 从出生自然捕食鱼群，确认初期成长明显顺畅，同时不会过快跳过中期。
- 依次验证大白鲨、鮟鱇、大王乌贼、邓氏鱼的追击速度与冲刺脱险，确认领主不会被普通直线加速轻松甩开。
- 测试重伤、轻伤、满血的进食分配，核对实际回血、成长与饱食提示；检查海鸥与主宰战利品的一致性。
- 验证四种主宰的领地、前摇、技能、3 秒虚弱、咬击距离和冷却；确认狂食不会跳过多次战斗。
- 确认每局只启用两只随机主宰，撤退后保留伤害，击败后不会立即成群重生。
- 验证 30 米但未击败主宰时不会胜利，至少一位主宰加 30 米才结算。
- 用不同体型从水面跃起，确认天空、水花、海鸥、落水及镜头连续；测试重开与暂停时没有残留空中状态。
- 检查奖励的十字、双箭头、獠牙、名称与效果文字在远近和窄屏的可辨识性。
- 实际探索最深可达海域，核对世界最大海深 740、显示倍率 4、地形边界、物种栖息地和领地位置。
- 试听平静、追击、主宰、脱险、暂停和胜利全过程，确认交叉渐变、音量和效果提示；胜利音效不要被立即暂停截断。
- 在真实手机上验证摇杆、冲刺、声呐、主动咬击、多指操作与页面安全区。
- 本轮构建、临时预览与 review 包已完成；后续改动继续更新对应验证记录与试玩版本。

## 玩法与难度调优

记录自然完整一局中各阶段耗时、捕食次数、治疗量、死亡原因和主宰攻击次数。重点观察是否因缺乏食物或过长成长停滞而失去探索动力，是否出现贴身硬拼优于躲技能、反击窗口过短或撤出领地后无法恢复的情况。

评估主宰重生间隔、两只主宰的随机组合和位置，减少无法接近或重复游走的空白时间。现有数值属于起始方案，调整时保留普通猎手与主宰的逃生方式差异。

## 美术与声音迭代

- 精修虎鲸体态、口部、鳍部、皮肤和游泳动画；调整大王乌贼与克拉肯的轮廓差异。
- 打磨玛雅灵感原创巨兽和三头海德拉的可读轮廓、技能动作与弱点表现，避免依靠文字才能辨认。
- 加强主宰入场的远处阴影、环境反应与独立动作，让体型和危险在正式交战前可以感知。
- 调整更深海域的光照、荧光、雾与熔岩亮度，保持深海氛围并让重要目标可辨认。
- 配乐已有明确旋律与节拍；下一步通过真实设备试听调整音乐与音效音量，补充不同海域的编曲变化。
- 为后续真实声效收集或制作有明确授权的水下环境、捕食、碰撞与海怪素材，并记录来源；当前仍为程序合成音频。

## 操作与可访问性

- 调优触屏摇杆、双指冲刺与咬击按钮位置，考虑横屏和竖屏差异。
- 增加鼠标灵敏度、俯仰反转和镜头强度选项。
- 检查成长后的视野、转向惯性和主宰贴身战相机，减少遮挡与不适。
- 提供减弱动态镜头、心跳和受伤闪烁的设置。
- 将初次主宰战、奖励和修复机制用短提示逐步解释。

## 可选玩家角色与后期内容

当前仍只开放虎鲸。后续可以尝试一条差异明确的新角色，再扩展选择界面：海豚偏机动与恢复，鲨鱼偏捕食但食物需求更高，深海鱼偏低光探索或诱饵能力。各角色要有独立成长、速度、体力、需求和动画，避免只换模型。

玛雅灵感巨兽、三头海德拉、大王乌贼和邓氏鱼已进入 v0.2 实现，不再列作“尚未加入”的后期内容。后续应优先打磨它们的区别和战斗，再考虑新海怪、稀有猎物、遗迹支线或更高风险奖励路线。

## 技术整理

- 根据实际性能降低不可见生物、技能特效与音频声部的无效工作，检查长时间运行和重复重开的资源释放。
- 改善大型生物、岩拱和主宰技能的碰撞近似，尤其是贴地位置与撤回领地时的处理。
- 保持生存规则、主宰规则和场景表现分离，为复杂状态补充有效回归检查。
- 保留浏览器专项与自然试玩结果的区别，将最新结论单独更新到验证记录。
- 后续版本继续先 review，再依照明确授权提交、推送和发布；临时预览不代替 GitHub Pages。
