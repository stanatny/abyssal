## Authorization and scope

On 2026-11-01 the user requests publishing the existing work to main, following

plus the reviewed White Tiger head correction. Before publication metadata,

This integration includes:

- All-region ecology coverage, shallow-to-deep danger progression, and lord-side
  retaliating predators and limited recovery food.
- Creature-specific upright posture and turning, independent attack aiming,
  Penglai ground strides, head alignment, solid floating islands and HF bamboo.
- Temporary horizontal near-surface currents in Hawaii, Atlantis, Bermuda and
  Odyssey, with visible flow direction, downstream force and upstream resistance.
- One randomly selected Atlantis puzzle per expedition: a touch-operated
  water-level lock, distributed light seal or five-stage mural memory route.
  Water-level submission failure resets the lock and penalizes the player;
  light has no puzzle penalty; mural failure penalizes only the current gate
  and preserves passed stages. These family-specific rules remain distinct.
- Poseidon's light-seal awakening, four distinct quest cues, mounted reflectors,
  animated gate membranes and repository puzzle design rules.
- Corrected White Tiger skull geometry and fitted head, jaw and mouth anchors,
  with its accepted movement, combat timing, attack range and damage preserved.

The proposed midgame hunting mechanics are still undecided and are not
implemented. No tag, separate GitHub Release or personal Skill edit is included.
